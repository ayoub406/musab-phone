# موقع مصعب فون - حجز آيفون 18

موقع ويب مبني بـ **Python (Flask)** لحجز أجهزة آيفون 18، بهوية بصرية باللونين
الأبيض والأزرق، مع عداد تنازلي حي لموعد المؤتمر ونزول الجهاز.

## آخر التحديثات
- **شعار جديد أوضح**: تصميم SVG حاد (هاتف + إشارة سرعة) بتدرّج أزرق-كحلي
  يظهر في كل الصفحات؛ إذا أضفتم `static/img/logo.png` سيحل محله تلقائياً.
- **العملة دينار ليبي (د.ل)** جاهزة في الكود، لكن **الأسعار مخفية حالياً**
  عن الزوار لأن السعر النهائي لم يُحدَّد بعد (الموقع حجز بدون سعر ظاهر).
  راجع قسم "الأسعار" بالأسفل لتفعيلها لاحقاً بضغطة واحدة.
- **طباعة/تحميل الباركود**: صفحة الشكر فيها الآن زر "🖨️ طباعة الباركود"
  يفتح نافذة طباعة منسّقة (بطاقة الباركود فقط، بدون بقية عناصر الصفحة)،
  وزر "⬇️ تحميل الباركود" يحفظ صورة الرمز مباشرة على جهاز العميل.
- **رسم بياني حي لنمو الحجوزات** في الصفحة الرئيسية (قسم "الحجوزات")،
  يرتفع الخط تلقائياً مع كل عملية حجز جديدة (يتحدّث كل 8 ثوانٍ).
- **أيقونات فيسبوك / تيك توك / انستقرام** في الهيدر والفوتر، تفتح صفحات
  التواصل الفعلية للشركة في تبويب جديد عند الضغط.
- **قائمة موبايل (Hamburger)**: على الشاشات الصغيرة تظهر أيقونة ☰ تفتح
  قائمة تصفح كاملة، بدل اختفاء الروابط بالكامل كما كان سابقاً.
- حركات ظهور خفيفة وسلسة عند التمرير لبطاقات المميزات والموديلات والمعرض.

## المميزات
- صفحة رئيسية احترافية (Hero + مميزات + معرض ألوان + موديلات + نموذج حجز)
- عداد تنازلي (أيام / ساعات / دقائق / ثوانٍ) لموعد المؤتمر ونزول الهاتف
- **رمز QR حقيقي لكل حجز** يحتوي كامل بيانات العميل (الاسم، الجوال، الموديل،
  اللون، السعة، رقم الحجز...) يظهر في صفحة الشكر، ويحضره العميل معه عند
  الاستلام لمطابقة بياناته
- **عداد كمية حي (100 جهاز)**: ينقص تلقائياً مع كل حجز حقيقي، مع شريط تقدّم
  ونسبة مئوية تتحدث كل 8 ثوانٍ بدون تحديث الصفحة، ويُغلق الحجز تلقائياً عند
  نفاد الكمية (مفروض أيضاً من السيرفر وليس فقط شكلياً)
- **معرض 5 صور** للهاتف بألوان مختلفة (راجع static/img/README_IMAGES.txt)
- **رقم قسم الصيانة** ظاهر في الهيدر والفوتر وصفحة الشكر
- **زر واتساب** في صفحة الشكر يفتح محادثة جاهزة مع الشركة تحتوي تفاصيل الحجز
  (انظر قسم "الواتساب" أدناه لتفعيل الإرسال التلقائي لاحقاً)
- مكان مخصص لشعار الشركة في الهيدر (يظهر تلقائياً عند إضافة الصورة)
- نموذج حجز يحفظ البيانات في قاعدة بيانات SQLite
- لوحة تحكم بسيطة محمية بكلمة مرور لعرض/حذف الحجوزات (`/admin`)
- تصميم متجاوب (Responsive) بالكامل على الجوال والتابلت والكمبيوتر
- دعم كامل للغة العربية واتجاه RTL

## طريقة التشغيل

1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

2. تشغيل الموقع:
```bash
python app.py
```

3. افتح المتصفح على:
```
http://127.0.0.1:5000
```

## إضافة الصور (الشعار + 5 صور الهاتف)
راجع الملف: `static/img/README_IMAGES.txt`
يشرح بالتفصيل أسماء الملفات المطلوبة بالضبط ومكان وضعها.
باختصار:
- الشعار: `static/img/logo.png`
- صور الهاتف: `static/img/phone-1.jpg` إلى `phone-5.jpg`

إذا لم تُضَف الصور، الموقع يعمل بشكل طبيعي مع أيقونات بديلة تلقائياً.

## رمز QR الخاص بالحجز
عند إتمام أي حجز، يولّد النظام تلقائياً صورة QR فريدة تحتوي كامل بيانات
الحجز (بصيغة JSON) وتُحفظ في `static/qrcodes/`. يظهر الرمز في صفحة الشكر
بعد الحجز مباشرة، ويُطلب من العميل حفظه/طباعته وإحضاره عند استلام الجهاز
للتحقق من بياناته بمجرد مسح الرمز بأي تطبيق قارئ QR.

> اخترنا QR بدلاً من الباركود التقليدي (Code128) لأن الباركود العادي يقدر
> يخزن رقم قصير فقط، بينما QR يقدر يخزن كل بيانات الحجز كاملة داخل الرمز نفسه.

## الكمية المتاحة (100 جهاز)
معدل `TOTAL_STOCK = 100` في أعلى `app.py`. العدد المتبقي يُحسب مباشرة من
عدد الحجوزات الحقيقية في قاعدة البيانات (وليس رقم وهمي)، ويظهر في:
- شريط تقدّم حي في الصفحة الرئيسية (يتحدث تلقائياً كل 8 ثوانٍ عبر `/api/stock`)
- لوحة التحكم `/admin`

وعند وصول الحجوزات إلى 100، يُغلق الحجز تلقائياً من السيرفر (رسالة خطأ
واضحة للعميل) وليس فقط من الواجهة، فلا يمكن تجاوز الكمية.

## قسم الصيانة ورقم الواتساب
عدّل هذي القيم من أعلى `app.py`:
```python
MAINTENANCE_PHONE = "0922051000"           # رقم قسم الصيانة
WHATSAPP_BUSINESS_NUMBER = "218922051000"  # رقم واتساب الشركة (صيغة دولية)
```
حالياً الموقع يستخدم رابط "click-to-chat" (`wa.me`) يفتح واتساب العميل
برسالة جاهزة موجّهة لرقم الشركة (العميل يضغط زر واحد ويرسلها). هذا لا
يحتاج أي حساب أو مفاتيح API.

### لتفعيل إرسال تلقائي 100% من السيرفر لحظة الحجز
إذا رغبتوا لاحقاً أن يصل للعميل تلقائياً رسالة "تم تأكيد حجزك" من رقم
الشركة بدون أي تدخل من العميل، هذا يتطلب حساب **WhatsApp Business
Cloud API** من Meta (مجاني للاستخدام المحدود) وتحتاجون:
1. حساب Meta for Developers + WhatsApp Business App
2. رقم هاتف مُوثّق (Phone Number ID) + Access Token
3. إضافة كود استدعاء `https://graph.facebook.com/v20.0/{phone_number_id}/messages`
   داخل دالة `reserve()` في `app.py` بعد حفظ الحجز مباشرة

بمجرد توفر هذي البيانات، أقدر أضيف الكود الفعلي للإرسال التلقائي مباشرة.

## إعداد موعد المؤتمر / نزول الهاتف
موعد انتهاء الحجز محسوب تلقائياً في `app.py`:
```python
RESERVATION_DEADLINE = (datetime.now() + timedelta(days=11)).replace(hour=19, minute=0, ...)
```
أي: بعد 11 يوماً من تشغيل الموقع، الساعة 7:00 مساءً.
يمكنك تعديل الرقم `11` أو الساعة `19` حسب موعدكم الفعلي، أو استبدال السطر
بتاريخ ثابت مثل:
```python
RESERVATION_DEADLINE = datetime(2026, 9, 9, 19, 0, 0)
```

## الأسعار (دينار ليبي) - كيف تفعّلونها لاحقاً
في أعلى `app.py`:
```python
SHOW_PRICES = False   # غيّرها إلى True لإظهار الأسعار للزوار
```
وبعدها عدّلوا رقم كل موديل بالدينار الليبي داخل قائمة `MODELS`:
```python
MODELS = [
    {"id": "iphone18", "name": "iPhone 18", "price": 8500},  # مثال فقط
    ...
]
```
العملة نفسها (`د.ل`) معرّفة في متغيّر `CURRENCY` أعلى الملف ولا تحتاج تعديل.

## الرسم البياني لنمو الحجوزات
كل حجز جديد يُضاف كنقطة على الخط عبر مسار `/api/timeline`، ويتحدّث تلقائياً
كل 8 ثوانٍ في الصفحة الرئيسية بدون الحاجة لتحديث المتصفح (نفس أسلوب عداد
الكمية). لا يحتاج أي إعداد إضافي.

## طباعة وتحميل الباركود (QR)
في صفحة الشكر بعد كل حجز:
- **🖨️ طباعة الباركود**: يفتح نافذة طباعة المتصفح لكن بتنسيق خاص يُظهر
  فقط بطاقة الباركود وبيانات الحجز (بدون هيدر أو أزرار)، جاهزة للطباعة
  أو الحفظ كـ PDF مباشرة.
- **⬇️ تحميل الباركود**: يحفظ صورة الرمز (PNG) مباشرة على جهاز العميل.

## روابط التواصل الاجتماعي

```python
SOCIAL_LINKS = {

    "tiktok": "...",
    "instagram": "...",
}
```
لتغيير أي رابط مستقبلاً، عدّلوه هنا فقط وسيتحدّث في كل الصفحات تلقائياً.

## لوحة التحكم
- الرابط: `http://127.0.0.1:5000/admin`
- كلمة المرور الافتراضية: `musab2026`
- تعرض الآن أيضاً: رقم مرجع كل حجز، والمتبقي من الـ 100، ونسبة الحجز
- **مهم:** غيّر كلمة المرور (`ADMIN_PASSWORD`) و `app.secret_key` في ملف `app.py`
